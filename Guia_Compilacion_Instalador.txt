Guía: Compilar, Publicar, ZIP Portable y Generar Instalador (Inno Setup)

Proyecto: IgameToolsWinForms (WinForms .NET 8)
Ejecutable principal: IgameToolsWinForms.exe
Versión instalador: 0.1.0
Carpeta del proyecto: d:\xampp\htdocs\IgameTools

------------------------------------------------------------
1) Preparar cambios (código y recursos)
------------------------------------------------------------

- Recursos usados por la app:
  - img/ (icono y recursos visuales)
  - csv/ (CSV de ejemplo y/o ficheros auxiliares)

- Verifica que el proyecto compila:
  1. Abrir PowerShell en:
     d:\xampp\htdocs\IgameTools
  2. Ejecutar:
     dotnet build

------------------------------------------------------------
2) Publicar binarios (Release, self-contained, single-file)
------------------------------------------------------------

Ejecutar en PowerShell desde la carpeta del proyecto:
  d:\xampp\htdocs\IgameTools

# (Opcional) limpiar publicación previa
Remove-Item -Path .\publish\* -Recurse -Force -ErrorAction SilentlyContinue

# Publicar binarios actualizados en single-file, win-x64
dotnet publish IgameToolsWinForms.csproj -c Release -r win-x64 --self-contained true /p:PublishSingleFile=true /p:PublishTrimmed=false -o publish/win-x64-singlefile

# Copiar recursos (img y csv) dentro de win-x64-singlefile
$ErrorActionPreference = 'Stop'
$dest = Join-Path $pwd 'publish\win-x64-singlefile'
if (!(Test-Path $dest)) { throw "No existe: $dest" }

if (Test-Path 'img') {
  Copy-Item -Path 'img' -Destination (Join-Path $dest 'img') -Recurse -Force
}

if (Test-Path 'csv') {
  Copy-Item -Path 'csv' -Destination (Join-Path $dest 'csv') -Recurse -Force
}

# Verificar el ejecutable publicado
Get-Item .\publish\win-x64-singlefile\IgameToolsWinForms.exe |
  Select-Object Name, LastWriteTime, Length

------------------------------------------------------------
3) Generar el instalador con Inno Setup
------------------------------------------------------------

Requisitos:
- Inno Setup 6 instalado.
  Rutas típicas:
  - C:\Program Files (x86)\Inno Setup 6\ISCC.exe
  - C:\Program Files\Inno Setup 6\ISCC.exe

Desde d:\xampp\htdocs\IgameTools:

$ErrorActionPreference = 'Stop'

# Localizar ISCC
$iss = 'C:\Program Files (x86)\Inno Setup 6\ISCC.exe'
if (!(Test-Path $iss)) { $iss = 'C:\Program Files\Inno Setup 6\ISCC.exe' }

# Compilar installer.iss y generar el .exe en .\publish
# Nota: puedes pasar versión usando /DMyAppVersion=0.1.0
& "$iss" /Sspawn=0 /V=1 /O"$pwd\publish" "$pwd\installer.iss"

Salida esperada del instalador:
  d:\xampp\htdocs\IgameTools\publish\IgameTools_0.1.0_Setup.exe

------------------------------------------------------------
3b) Crear versión portable (ZIP)
------------------------------------------------------------

Desde la misma carpeta del proyecto:

$ErrorActionPreference = 'Stop'

$out = 'publish/IgameTools_0.1.7_Portable.zip'
if (Test-Path $out) { Remove-Item $out -Force }

Compress-Archive -Path 'publish/win-x64-singlefile/*' -DestinationPath $out -Force

Salida esperada del portable:
  d:\xampp\htdocs\IgameTools\publish\IgameTools_0.1.7_Portable.zip

------------------------------------------------------------
3c) Crear ZIP win-x64 (single-file)
------------------------------------------------------------

Desde la misma carpeta del proyecto:

$ErrorActionPreference = 'Stop'

$out = 'publish/IgameTools_0.1.7_win-x64_singlefile.zip'
if (Test-Path $out) { Remove-Item $out -Force }

Compress-Archive -Path 'publish/win-x64-singlefile/*' -DestinationPath $out -Force

Salida esperada del ZIP win-x64 single-file:
  d:\xampp\htdocs\IgameTools\publish\IgameTools_0.1.7_win-x64_singlefile.zip

------------------------------------------------------------
4) Verificar que el instalador incluya recursos
------------------------------------------------------------

- Asegúrate de que el instalador incluye:
  - img\...
  - csv\...

Si falta algo:
- Comprueba que existe en la ruta correcta dentro del repo.
- Comprueba que está versionado (git add ...).

------------------------------------------------------------
5) Fallback: limpieza completa si algo queda obsoleto
------------------------------------------------------------

Si sospechas que el instalador o el portable llevan archivos antiguos:

Remove-Item -Path .\publish\* -Recurse -Force -ErrorAction SilentlyContinue

dotnet clean

dotnet restore

dotnet publish IgameToolsWinForms.csproj -c Release -r win-x64 --self-contained true /p:PublishSingleFile=true /p:PublishTrimmed=false -o publish/win-x64-singlefile

$iss = 'C:\Program Files (x86)\Inno Setup 6\ISCC.exe'
if (!(Test-Path $iss)) { $iss = 'C:\Program Files\Inno Setup 6\ISCC.exe' }
& "$iss" /Sspawn=0 /V=1 /O"$pwd\publish" "$pwd\installer.iss"
